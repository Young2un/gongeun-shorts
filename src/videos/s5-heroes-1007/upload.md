```

## 설명

```
솜브라 리워크에 가려진 5시즌 영웅 변경을 2026년 10월 7일 패치 노트 기준으로 정리했습니다.
영웅 34명의 타점이 조정됐고(루시우 머리 13.2→16, 캐서디 몸통 37→33 등) 히트스캔 투사체는
대형 0.07→0.04미터로 줄었습니다. 독트린은 궁극기 비용 8% 증가, 추진형 장막 치명타 면역 제거,
구제 지속 8초→6초. 캐서디는 황야의 무법자 중 제트팩 캣 생명줄 불가. 겐지 질풍참 50→60,
D.Va 마이크로 미사일 초당 11→14발, 루시우 소리 방벽 5초→6초, 도미나·엠레 상향, 바스티온 재설정 6초→5초,
아나·시온 특전 교체. 로드호그는 고철총 2연발, 쓰레기 압축기 추가, 사슬 갈고리 최종 거리 3→4.5미터,
숨 돌리기 초당 150→200. 솜브라는 지원으로 바뀌며 해킹·바이러스 삭제, 긴급 패치·사이버 스페이스 추가
(약화: 주는 피해·치유 50% 감소, EMP 비용 67.5% 증가).

## 공지 원문과 대조한 것

모든 수치를 넥슨 패치 노트 844 에서 다시 확인했다.

- **타점 조정 영웅 수**: 섹션을 세어 보니 34명이 맞다 (아나 · 안란 · 애쉬 · 바티스트 · 바스티온 · 캐서디 · 둠피스트 · 에코 · 엠레 · 한조 · 해저드 · 일리아리 · 제트팩 캣 · 정커퀸 · 정크랫 · 주노 · 키리코 · 라이프위버 · 루시우 · 마우가 · 메르시 · 미즈키 · 모이라 · 라인하르트 · 시에라 · 소전 · 솜브라 · 시메트라 · 토르비욘 · 트레이서 · 벤처 · 레킹볼 · 우양 · 젠야타).
- 루시우 13.2→16 · 키리코 14.9→16 · 메르시 14.4→17 · 솜브라 14→16 · 캐서디 몸통 37→33 · 젠야타 20→17 · 토르비욘 23.3→20: 원문과 일치.
- 히트스캔 대형 0.07→0.04 · 소형 0.04→0.02, 개발자 의견("비슷한 수준의 효율을 유지하고자"): 일치.
- 독트린 조정(궁극기 비용 8% · 수혈 50% · 활기 드론 35→30 · 추진형 장막 7→8초, 50→40%, 치명타 면역 제거 · 구제 4→5, 8→6초, 5→4초): 일치.
- 캐서디 "황야의 무법자: 제트팩 캣의 생명줄에 붙을 수 없습니다" + 개발자 의견: 일치.
- 겐지 · D.Va · 루시우 · 도미나 · 엠레 · 바스티온 · 아나 국소 마취(혼미 제거) · 시온 생존 본능(키네틱 재장전 제거): 일치.
- 로드호그: 고철총 2연발 · 탄약 6→12 · 연발당 175→204 · 치명타 2→1.5 · 산탄 25→16, 7→4.25 · 탄 퍼짐 8→6 · 투사체 속도 80→100 · 쓰레기 압축기(2초, 30%, 75~200) · 갈고리 0.4→0.3초, 3→4.5m, 7→6초(5대5) · 숨 돌리기 3→2초, 150→200, 40→35%, 1.25→2초 · 특전 이리 와 꼬마 돼지야(80%) · 독기 배출(30% 둔화, 초당 20): 일치. 돼재앙 자체도 제거됐다고 나오는데 영상에서는 다루지 않았다.
- 솜브라: 지원 전환 · 해킹/바이러스 삭제 · 긴급 패치(65 + 초당 25, 총 175, 12초, 충전 2회) · 사이버 스페이스(5m, 3초, 50%) · 공모자 · EMP 25→20%, 비용 67.5% 증가 · 위치변환기 18→12.25m, 6→7.5초: 일치.

```console
npm run voice:gemini -- --video s5-heroes-1007
npm run captions -- --video s5-heroes-1007
npm run voice:check -- --video s5-heroes-1007
npx remotion render S5Heroes1007 out/s5-heroes-1007.mp4
npx remotion render S5Heroes1007Rich out/s5-heroes-1007-rich.mp4
```

장면만 보려면 Studio 의 `S5Heroes1007-Scenes` (`S5H-1` ~ `S5H-14`), 화려한 판은 `S5Heroes1007Rich-Scenes` (`S5HR-…`).
